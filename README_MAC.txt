====================================================================
           PIXAZON SLINGSHOT INTERACTIVE WALL - MAC SETUP
====================================================================

NO INSTALLATION OR DOWNLOADS REQUIRED!
This package includes everything:
  • Standalone Node.js runtime for Apple Silicon (M1/M2/M3/M4)
  • Standalone Node.js runtime for Intel Macs
  • All required server libraries and dependencies
  • SSL certificates for phone motion sensors

--------------------------------------------------------------------
HOW TO RUN ON YOUR MAC (EASY 2-CLICK LAUNCH):
--------------------------------------------------------------------

1. EXTRACT the downloaded RAR / ZIP file to your Mac (e.g. into Documents or Desktop).

2. Open the extracted folder and double-click:
   👉 Start_Slingshot_Mac.command

   • It will start the server and automatically launch the TV screen
     in your browser (http://localhost:3000/tv.html).
   • Connect your phone to the same Wi-Fi network and scan the QR code
     on the screen to start slingshotting!

--------------------------------------------------------------------
NOTE: IF macOS SHOWS A PERMISSION WARNING ON FIRST CLICK:
--------------------------------------------------------------------
macOS security may prevent downloaded scripts from running until granted
permission. If macOS says "cannot be opened because it is from an unidentified developer"
or "you don't have permission":

Option 1 (Fastest):
  • Right-click (or Two-Finger Click) "Start_Slingshot_Mac.command"
  • Click "Open"
  • Click "Open" again in the confirmation prompt.

Option 2 (Terminal 1-second unlock):
  • Open the Terminal app on your Mac
  • Type:
       chmod +x 
    (make sure to leave a space after +x)
  • Drag the file "Start_Slingshot_Mac.command" into the Terminal window
  • Press ENTER.
  • You can now double-click "Start_Slingshot_Mac.command" normally!

====================================================================
TO STOP THE APP:
Simply close the Terminal window or press Ctrl+C inside it.
====================================================================
